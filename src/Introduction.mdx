<Subtitle>React-based design system for Aibel applications based on Digdir designsystemet</Subtitle>

This package provides reusable UI building blocks and app helpers for internal Aibel solutions, including:

- Designsystem basics (e.g. `Button`, `Card`, `Badge`, `Checkbox`, `Popover`)
- Aibel components (e.g. `HeaderBar`, `SubHeaderBar`, `FooterBar`)
- Hooks (e.g. `useLocalStorage`)
- Icons

The library is built with React, TypeScript, Vite, Storybook, Tailwind CSS, and Digdir Designsystemet components.

For further documentation of the Designsystemet components visit their website: [Digdir](https://designsystemet.no/no/components)

## 🎯 Purpose

This Storybook serves as:

- 📦 **A component library** – reusable, well-documented UI components
- 🧭 **A design reference** – visual and behavioral guidance
- 🔧 **A development tool** – interactive playground for component props
- 📖 **Single source of truth** – reducing ambiguity and duplication

## 🧱 What’s inside

You’ll find the following sections in this Storybook:

### Foundations

Core design foundations that everything else builds on, such as:

- Colors
- Typography
- Spacing & layout

### Components

Reusable UI building blocks, documented with:

- Usage guidelines
- Variants and states
- Interactive prop controls
- Accessibility considerations

### Patterns

Higher-level compositions and UI patterns that solve common problems using multiple components.

## 🧑‍💻 How to use Storybook

### 1. Browse components

Use the navigation panel on the left to browse categories and components.

### 2. Interact with components

Each component comes with **Controls**, allowing you to:

- Change props
- Toggle states
- Test edge cases
- Explore variations

## 🔄 Versioning & stability

- Components marked as **stable** are safe for production use.
- Experimental or evolving components may be marked accordingly.

## 📎 Helpful tips

- Use **Canvas** to focus on visual testing
- Use **Docs** to understand behavior and guidelines
- Reset Controls to return to default component states
- Test edge cases by pushing props beyond normal values
